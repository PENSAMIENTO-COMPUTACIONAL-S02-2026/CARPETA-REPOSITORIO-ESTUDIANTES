# 1. Primeros avances de la computación

## Charles Babbage

### Máquina Diferencial (1822)

Charles Babbage diseñó una máquina capaz de automatizar operaciones matemáticas y reducir errores humanos en los cálculos.

### Máquina Analítica (1834–1837)

Fue el primer diseño que planteó una computadora programable.

Incorporaba conceptos que siguen presentes en los computadores actuales:

- Unidad de procesamiento
- Memoria
- Instrucciones mediante tarjetas perforadas

---

## Telar de Jacquard (1801)

Joseph Marie Jacquard creó un telar automatizado controlado por tarjetas perforadas.

### Importancia histórica

Introdujo ideas fundamentales para la computación moderna:

- Diferencia entre hardware y software
- Funcionamiento binario
- Organización de imágenes mediante una cuadrícula similar a los píxeles

---

## Ada Lovelace

Ada Lovelace es reconocida como la primera programadora.

### Contribuciones

- Desarrolló el primer algoritmo pensado para una máquina.
- Comprendió que una computadora podía trabajar con distintos tipos de información, no únicamente números.

---

## Alan Turing

### Máquina de Turing (1936)

Alan Turing propuso un modelo teórico capaz de ejecutar instrucciones sobre una cinta infinita.

### Aporte principal

Demostró que cualquier proceso computacional puede representarse mediante reglas y algoritmos.

# 3. Relación entre computación y arte

## Arte computacional en los años 60

Durante la década de 1960 comenzaron las primeras experiencias artísticas realizadas con computadoras y algoritmos.

### Características

- Generación de imágenes mediante código
- Uso creativo de sistemas computacionales
- Experimentación visual y matemática

---

## Sketchpad — Ivan Sutherland

Sketchpad fue uno de los primeros programas de dibujo interactivo.

### Innovaciones

- Manipulación gráfica directa
- Interacción humano-computador
- Base de los futuros programas de diseño digital

---

## Douglas Engelbart

Introdujo elementos esenciales de las interfaces modernas:

- Mouse
- Ventanas
- Representación gráfica mediante bits

---

# 4. Software libre y programación creativa

## Software Libre — Richard Stallman

En 1983 Richard Stallman impulsó el proyecto GNU y el movimiento de software libre.

### Principios

- Libertad para usar programas
- Acceso al código fuente
- Posibilidad de modificar y compartir software

---

## Design By Numbers — John Maeda

Proyecto educativo creado para acercar la programación a artistas y diseñadores.

### Objetivo

Convertir el código en una herramienta accesible para la creación visual.

---

## Processing (2001)

Desarrollado por Casey Reas y Ben Fry.

### Finalidad

Facilitar el aprendizaje de programación visual y creativa.

### Características

- Código abierto
- Uso simple
- Orientado a artistas y principiantes

---

## p5.js

Biblioteca derivada de Processing enfocada en programación creativa para la web.

### Características principales

- Accesible y educativa
- Basada en JavaScript
- Pensada para experiencias visuales e interactivas
